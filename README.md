# AutoHotkey scripts

Small, free [AutoHotkey v2](https://www.autohotkey.com/) scripts for Windows. Each one is a
single `.ahk` file with no other dependencies: install AutoHotkey v2, download the script and
double-click it.

| Script | What it does |
| --- | --- |
| [Unzip Latest Download](unzip-latest-download/) | Press Ctrl+Shift+U in File Explorer to unzip your newest download into the folder you're in. |
